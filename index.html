Manage Workspace Data

Upload your workspace files to run the locator verifier completely offline inside your browser. Drag and drop files, or select them manually. All data is saved locally in your browser's IndexedDB database.

📄 File Upload & Naming Guide

To run the locator verifier offline, upload your page assets in the two columns below:

1. HTML/MHTML Files Column:

Upload one or more .mhtml or .html page captures. These are the screens where your locators will be verified.

2. JSON Config Column:

Upload the UI elements configuration JSON file which defines the pages, elements, and selectors.

🗺️ Interactive Mapping:

Once both inputs are populated, the "Proceed to Mapping" button will appear. You will then be able to drag-and-drop the uploaded screens to pair them with the pages listed in the JSON configuration, and edit page or file titles.
